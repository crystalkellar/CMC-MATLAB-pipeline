# CMC-MATLAB-pipeline
EEG and EMG preprocessing, CMC analysis and control checks used in Ms SL. Chambers' project

EEG preprocessing, EMG preprocessing and EMG baseline preprocessing are done first within the pipeline to clean and filter the raw EEG and EMG data

The EEG datasets are then segmented into the corresponding trials in EEG segments and EEG baseline segments

CMC analysis can then be run with the preprocessed and corresponding EEG and EMG data

IMC analysis, Muscle activation code and Positive control analysis are the control checks done thereafter
